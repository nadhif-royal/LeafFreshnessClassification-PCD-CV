## Overview

This repository contains the complete source code, image preprocessing pipelines, machine learning models, deep learning architectures, and live demonstration scripts for the **Campus Leaf Freshness Classification** system. 

Developed using a primary dataset collected directly within the **Universitas Brawijaya (UB)** campus environment, this project classifies plant leaves into three distinct physiological freshness states:
1. **Healthy Leaf (`sehat`)**: Fresh green leaves with intact surfaces and uniform pigmentation.
2. **Yellowing Leaf (`menguning`)**: Transitional leaves showing chlorophyll degradation and yellow discoloration.
3. **Dried Leaf (`kering`)**: Senescent or fallen brown leaves with dehydrated, brittle textures.

Beyond achieving high classification metrics, the primary objective of this research project is to conduct a critical ablation study analyzing how **Digital Image Processing (PCD)** techniques impact the performance of both **Classical Machine Learning** and **Deep Learning** models.

## System Pipeline & Methodology

The project enforces a strictly integrated workflow where the output generated by the Digital Image Processing module directly feeds into downstream feature extraction and model training:

```text
[UB Primary Leaf Dataset] 
       │
       ▼
[Digital Image Processing (PCD)]
  ├─ Color Space Conversion (RGB to HSV & CIE-LAB)
  ├─ Illumination & Contrast Enhancement (Gamma Correction & CLAHE)
  ├─ Edge-Preserving Denoising (Bilateral Filtering)
  └─ Leaf ROI Segmentation & Morphological Operations
       │
       ├───────────────────────────────────────────┐
       ▼                                           ▼
[Handcrafted Feature Extraction]           [Deep Learning Pipeline]
  ├─ Color Features (Color Histograms/Moments) ├─ Experiment B: Raw Image + DL
  └─ Texture Features (GLCM / LBP)             └─ Experiment C: PCD Image + DL
       │                                           │
       ▼                                           │
[Classical Machine Learning]                       │
  └─ Experiment A: PCD + Features + SVM/RF/KNN     │
       │                                           │
       └───────────────────┬───────────────────────┘
                           ▼
        [Quantitative Evaluation & Ablation Study]
          (Accuracy, Macro F1-Score, Confusion Matrix)
                           │
                           ▼
             [Real-Time OpenCV Demo System]

```

### Three Core Experimental Scenarios

To evaluate the effectiveness of Digital Image Processing prior to classification, we benchmark three primary experimental pipelines:

* **Experiment A (`PCD + Handcrafted Features + Machine Learning`):** Evaluates how classical classifiers perform using explicit color and texture descriptors extracted from preprocessed leaf images.
* **Experiment B (`Raw Image + Deep Learning`):** Establishes a baseline Deep Learning model trained directly on unedited, resized raw images.
* **Experiment C (`PCD + Deep Learning`):** Investigates whether contrast normalization (CLAHE), bilateral filtering, and background segmentation improve Deep Learning convergence and generalization.

1. **Clone the repository:**
```bash
git clone https://github.com/nadhif-royal/LeafFreshnessClassification-PCD-CV.git

```


2. **Install required dependencies:**
```bash
pip install -r requirements.txt

```


3. **Run the live OpenCV inference demo:**
